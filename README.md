# CYD PromptPay Terminal — Direct PromptPay iPad

เว็บสำหรับ iPad ที่สร้าง Thai PromptPay QR แบบระบุยอดเงิน และรับเงินเข้าปลายทาง PromptPay ที่ตั้งค่าไว้โดยตรง ไม่ใช้ Stripe และไม่ต้องต่ออุปกรณ์เสริม

## Deploy Vercel
1. Upload/Push ทั้งโฟลเดอร์ขึ้น GitHub
2. Import repository เข้า Vercel
3. ไม่ต้องตั้ง STRIPE_SECRET_KEY
4. เปิดเว็บบน iPad แล้วกด ตั้งค่า → ใส่เลขพร้อมเพย์ → บันทึก

## สำคัญเรื่องตรวจเงินเข้า
QR นี้เป็นการโอน PromptPay โดยตรง การสร้าง QR ไม่ได้ทำให้เว็บไซต์รู้เองว่าเงินเข้าบัญชีแล้ว หากต้องการสถานะ "จ่ายแล้ว" อัตโนมัติ ต้องเชื่อมต่อบริการ/Bank API ที่มี transaction inquiry หรือ webhook ที่รองรับบัญชีของคุณ เช่นบริการ QR/API ของธนาคารหรือผู้ให้บริการที่รองรับ

เลขพร้อมเพย์ที่กรอกจะถูกเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น
